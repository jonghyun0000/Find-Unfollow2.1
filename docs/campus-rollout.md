# 한림대 배포와 측정

## 이번 변경
- 한림대 키워드 `hallym` (근거: https://www.hallym.ac.kr/), `official`, 사용자 입력 키워드로 아이디 부분 일치 필터.
- 필터는 기본 해제. 개인 학생 계정이나 비공식 계정도 일치할 수 있으므로 공식 계정 판별 기능으로 설명하지 않는다.
- 숨긴 목록에서 이유 확인, 직접 확인 불가 표시 취소, 전체 초기화 가능. 원본 분석 결과/저장 기록은 바꾸지 않는다.
- 프로필은 사용자가 직접 열어본다. 비활성화, 삭제, 차단, 이름 변경, 로그인 제한을 자동 판정하지 않는다.
- 공유는 서비스 링크만 포함하며 계정 아이디, 팔로워 목록, 분석 수치는 포함하지 않는다.
- 캠페인 링크: `/?utm_source=hallym&utm_medium=share&utm_campaign=campus_launch`.
- UTM은 유입 구분용이며 이 변경만으로 방문·공유 이벤트를 저장하거나 운영자에게 보내지 않는다.

## 아직 수집하지 않는 정보
현재 앱은 분석 파일과 목록을 서버에 보내지 않는다. 운영자는 이용자의 인스타그램 아이디나 팔로워 관계를 조회할 수 없다. 서버가 페이지를 제공하면서 처리하는 호스팅 요청 로그와 인스타 분석 데이터 수집은 별개다.

운영자의 수집 범위 확정 및 측정 서비스 설정 전에는 분석 SDK/이벤트 전송을 활성화하지 않는다. 사용량 측정으로 진행할 경우 다음처럼 이벤트를 최소화한다:

| 이벤트 | 해석 | 보내지 않을 값 |
| --- | --- | --- |
| 방문 | 캠페인별 진입 | 입력 아이디, 임의 쿼리 문자열 |
| 실제 분석 완료 | 샘플을 제외한 분석 성공 | JSON, 파일명, 관계 목록, 계정 수 |
| 공유 버튼 클릭 | 공유 의도 | 공유 대상, 결과 데이터 |
| 설치 요청 수락 | 지원 브라우저에서만 가능한 설치 신호 | 사용자 계정 |
| standalone 실행 | 홈 화면 실행의 대리지표 | 지속적인 개인 식별자 |

공유창 완료는 수신자에게 전송되었다는 증거가 아니다. iOS 수동 홈 화면 추가의 정확한 완료 횟수는 웹에서 직접 수집할 수 없다. 설치 이벤트와 standalone 실행은 전체 고유 설치자 수가 아니다. 사용자 재방문율을 개인 단위로 측정하려면 별도의 식별/동의/보관 정책 판단이 필요하다.

Vercel Web Analytics 사용 시 프로젝트에서 활성화가 필요하며 custom events 지원 플랜을 확인한다:
- https://vercel.com/docs/analytics/custom-events
- https://vercel.com/docs/analytics/limits-and-pricing

## 다음 배포 확장
전국 대학은 대학별 공식 영문명과 실제 사용 아이디를 출처와 함께 확인한 목록을 만든 뒤 학교별 선택형 프리셋으로 추가한다. `hu`, `ku`, `su`처럼 짧고 중복되는 약칭이나 모든 대학의 단어를 기본 필터로 켜지 않는다. 현재는 사용자 입력란으로 다른 학교 영문명을 직접 추가할 수 있다.

바이럴 성과는 보장하지 않는다. 한림대에서 작은 배포를 시작해 파일 준비 단계 이탈, 분석 완료, 공유 링크 유입을 측정한 후 안내와 배포 문구를 개선한다.
